# Entrata AI Technical Coding Challenge

## Overview
Production-grade solutions for Task 1 (Profile Settings Form) and Task 2 (Cache Stale Reads Debug).

## Features
- **Task 1:** Responsive settings form with dynamic Zod client-side validation, accessible ARIA labels, specific error hints, and submit state management.
- **Task 2:** Data-fetch layer with query parameter cache keys, mutation invalidation, ETag handling, and interactive hit/miss logging.

## Setup & Running Instructions

### Install dependencies
npm install

### Start development server
npm run dev

### Run unit tests
npm test
